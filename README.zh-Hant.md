# 圓桌 · 我的 AI 團隊

在電腦上開啟群組網頁，讓研究員、策劃員、執行員、審核員依次發言，再由主管整合。每位成員使用獨立的真實 Codex 工作階段，透過對話紀錄接棒。

**無需 API key，無額外 API 費；使用現有 ChatGPT 訂閱的 Codex 額度，仍受方案用量限制。**

[English](README.md) · [完整使用說明](使用說明.md)

## 使用方式

1. 安裝 Node.js 20 或以上，以及近期官方 Codex CLI 或桌面版。
2. 執行 `codex login`，使用 ChatGPT 帳戶登入。
3. Windows 用戶雙擊 `Start.cmd`，開啟 http://127.0.0.1:4318 。
4. 輸入任務，選「全隊輪流」或指定成員。
5. 可停止討論、複製訊息、匯出 Markdown。雙擊 `Stop.cmd` 關閉服務。

不需要安裝第三方程式庫。亦可在終端機執行 `node server.mjs`。Windows 已作手動測試；macOS／Linux 尚未作手動驗證。

## 能力和限制

- 四位成員加主管共用一份 Codex 訂閱，全隊一輪會執行五次模型工作。
- 執行員交付文稿、分析及程式內容；不會操作其他應用程式、對外發布或發送訊息。
- 只有本機能連接，電腦及服務需要保持開啟。
- 模型處理仍需網絡，對話及上下文會傳給 OpenAI。歷史紀錄以未加密文字保存在本機 `data/history.json`。
- 程式不會讀取或複製登入檔；只接受 ChatGPT 登入，不會自動切換到 API 計費。
- 使用唯讀沙盒、停用 shell 工具並忽略使用者自訂 Codex 設定。這是原型，尚未經完整安全審計。

## 測試

執行 `npm run check` 和 `npm test`。自動測試只檢查本機服務，不會呼叫模型或消耗訂閱額度。
